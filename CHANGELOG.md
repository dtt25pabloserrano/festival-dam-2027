# Changelog

Todos los cambios relevantes del proyecto se documentan en este archivo.

## [0.1.0] - 2026-11-13

### Añadido
- Estructura inicial del proyecto.
- Páginas `index.html`, `programa.html` y `entradas.html` con menú de navegación.
- Estilos comunes en `style.css`.
- Programa inicial con tres conciertos por día (principal a las 22:00).
- Entrada general de un día a 25 €.

## [v1.0] - 2026-11-19

### Añadido
- Completada la página `entradas.html` con condiciones básicas de compra y normas de acceso.
- Publicación de la web en GitHub Pages.
- Añadido el enlace a la web publicada en el `README.md`.
- Creación de la etiqueta `v1.0` para la primera versión estable del producto.
